# Disciplines of Python 

A collection of Python programs and practice exercises covering **Object-Oriented Programming (OOPs), File Handling, and core Python programming concepts**.

This repository is created for learning, practicing, and strengthening Python programming fundamentals through hands-on coding.

## 📚 Topics Covered

### 🐍 Object-Oriented Programming (OOPs)

Programs and practice related to:

* Classes and Objects
* Constructors
* Instance and Class Variables
* Methods
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Method Overriding
* Method Overloading concepts
* Practical OOP implementations

### 📁 File Handling

Python programs covering:

* Opening files
* Reading files
* Writing to files
* Appending data
* Working with different file modes
* Creating and modifying files
* Handling file-related operations
* Practical file-handling programs

### 💡 Python Programming Practice

Additional programs focused on improving:

* Python syntax
* Problem-solving
* Functions
* Conditional statements
* Loops
* Data structures
* Exception handling
* Programming logic

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/utkarsh0420/Disciplines-of-Python---OOPS-File-Handling.git
```

### 2. Navigate to the project

```bash
cd Disciplines-of-Python---OOPS-File-Handling
```

### 3. Run a Python program

```bash
python filename.py
```

For example:

```bash
python OOPS/classes_objects.py
```
